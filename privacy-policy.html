سیاست حفظ حریم خصوصی

در AnanasAI حریم خصوصی و کنترل کاربر بر اطلاعات شخصی اهمیت دارد. این سند توضیح می‌دهد هنگام استفاده از وب‌سایت و قابلیت‌های هوش مصنوعی آناناس، چه اطلاعاتی پردازش می‌شود، اتصال Google و GitHub چه دسترسی‌هایی ایجاد می‌کند و چگونه می‌توانید داده‌ها یا مجوزهای خود را حذف یا لغو کنید.

آخرین به‌روزرسانی: ۱۳ نوامبر ۲۰۲۶

۱. مسئول سرویس و راه ارتباطی

سرویس آناناس AI (AnanasAI) توسط تیم AnanasAI طراحی و ارائه می‌شود و توسعه نرم‌افزاری آن با همکاری تیم Branex انجام شده است.

برای پرسش‌های حریم خصوصی، درخواست دسترسی، اصلاح یا حذف اطلاعات، از پشتیبانی رسمی آناناس در تلگرام پیام بفرستید. لطفاً رمز عبور، توکن OAuth یا کد کامل فعال‌سازی اشتراک را در پیام عمومی یا برای اشخاص ناشناس ارسال نکنید.

۲. چه اطلاعاتی دریافت یا پردازش می‌شود؟

  • اطلاعات استفاده: پیام‌ها و درخواست‌هایی که وارد می‌کنید، فایل‌هایی که آگاهانه برای تحلیل انتخاب می‌کنید، و اطلاعات فنی لازم برای ارائه سرویس.
  • اطلاعات اشتراک: کد فعال‌سازی که برای احراز سطح دسترسی و محاسبه سهمیه استفاده می‌شود؛ کد فعال‌سازی در حافظه محلی مرورگر شما نیز نگهداری می‌شود.
  • تاریخچه گفتگو: گفتگوهای عمومی در حافظه محلی مرورگر ذخیره می‌شوند. تاریخچه منشی و کدنویس برای همگام‌سازی بین نشست‌ها در فضای ذخیره‌سازی سرور نگهداری می‌شود.
  • اطلاعات اتصال سرویس‌های ثالث: نشانی ایمیل و اطلاعات پایه حساب Google، توکن‌های دسترسی Google و GitHub به‌صورت رمزنگاری‌شده در سرور، و اطلاعات مخزن/شاخه‌ای که برای کار با GitHub انتخاب می‌کنید.
  • رسانه‌ها: فایل‌های صوتی کتابخانه محلی در مرورگر/دستگاه شما نگهداری می‌شوند؛ تصاویر ذخیره‌شده در کتابخانه آنلاین ممکن است در فضای ذخیره‌سازی سرویس نگهداری شوند.

۳. اتصال حساب Google چه دسترسی‌هایی می‌دهد؟

اتصال Google اختیاری است و فقط برای استفاده از قابلیت منشی هوشمند انجام می‌شود. در صفحه رضایت Google، مجوزهای زیر درخواست می‌شوند:

  • openid و email: شناسایی حساب و دریافت نشانی ایمیل برای نمایش اینکه کدام حساب متصل شده است.
  • https://www.googleapis.com/auth/gmail.readonly: خواندن ایمیل‌ها برای جست‌وجو و خلاصه‌سازی درخواستی کاربر. این مجوز به آناناس اجازه ارسال یا حذف ایمیل را نمی‌دهد.
  • https://www.googleapis.com/auth/gmail.send: ارسال ایمیل از طرف کاربر. متن و گیرنده پیش از ارسال به کاربر نمایش داده می‌شود و ارسال تنها پس از تأیید صریح او انجام می‌شود.
  • https://www.googleapis.com/auth/calendar.events.owned: دسترسی به رویدادهای تقویم‌هایی که کاربر مالک آن‌هاست. قابلیت فعلی برای مشاهده رویدادها و ایجاد رویداد جدید استفاده می‌شود؛ ثبت رویداد پس از نمایش پیش‌نمایش و تأیید کاربر انجام می‌شود.

محتوای ایمیل یا رویداد فقط هنگام اجرای درخواست مربوط به همان قابلیت پردازش می‌شود. برای نمونه، وقتی کاربر خلاصه ایمیل می‌خواهد، پیام‌های انتخاب‌شده برای تهیه خلاصه به سرویس مدل هوش مصنوعی ارسال می‌شوند. آناناس از داده‌های Google برای تبلیغات، فروش داده یا ساخت پروفایل تبلیغاتی استفاده نمی‌کند و آن‌ها را برای آموزش مدل عمومی خود به کار نمی‌گیرد.

توکن‌های Google در فضای ذخیره‌سازی سرور با رمزنگاری AES-GCM محافظت می‌شوند و برای برقراری اتصال و تمدید مجوز استفاده می‌شوند. داده‌های دریافتی از APIهای Google برای تبلیغات، فروش یا ساخت پروفایل تبلیغاتی استفاده نمی‌شوند و برای آموزش یا بهبود مدل‌های عمومی هوش مصنوعی به کار نمی‌روند. انتقال داده به پردازشگرهای فنی فقط در حد لازم برای ارائه قابلیتی انجام می‌شود که خود کاربر درخواست کرده است. دسترسی انسانی عادی به محتوای Gmail یا Calendar وجود ندارد؛ هر دسترسی استثنایی باید محدود به رضایت کاربر، درخواست پشتیبانی خود او، بررسی امنیتی/سوءاستفاده یا الزام قانونی باشد.

قطع اتصال و لغو مجوز Google

  1. در محیط چت، وارد بخش «منشی» شوید.
  2. در کادر اتصال حساب، گزینه «قطع اتصال» را انتخاب کنید. پیوند ذخیره‌شده در آناناس حذف و درخواست لغو توکن به Google ارسال می‌شود.
  3. برای اطمینان یا لغو مستقل دسترسی، به صفحه اتصالات حساب Google بروید و دسترسی AnanasAI را حذف کنید.

قطع اتصال، دسترسی آینده آناناس به حساب Google را متوقف می‌کند؛ اما ایمیل‌هایی که قبلاً ارسال شده‌اند یا رویدادهایی که قبلاً در تقویم ایجاد شده‌اند، از حساب Google شما حذف نمی‌شوند. در صورت نیاز باید آن‌ها را مستقیماً در Gmail یا Calendar حذف کنید.

۴. اتصال حساب GitHub چه دسترسی‌هایی می‌دهد؟

اتصال GitHub اختیاری و برای قابلیت کدنویس است. مجوز OAuth فعلی GitHub شامل repo و offline_access است.

  • repo: مجوز گسترده مخزن است و از نظر GitHub می‌تواند دسترسی خواندن و نوشتن به مخازن عمومی و خصوصی‌ای را که حساب GitHub شما اجازه دسترسی به آن‌ها را دارد فراهم کند. در عملکرد آناناس، مخزن و شاخه انتخاب‌شده برای خواندن فایل‌ها و بررسی کد استفاده می‌شود.
  • نوشتن تغییرات: کدنویس ابتدا تغییرات پیشنهادی را آماده و برای بازبینی نمایش می‌دهد. ایجاد شاخه، ثبت commit و ایجاد Pull Request پیش‌نویس تنها پس از دستور و تأیید کاربر انجام می‌شود. آناناس بدون درخواست کاربر، مخزن را تغییر نمی‌دهد.
  • offline_access: برای حفظ اتصال و تمدید دسترسی بدون نیاز به ورود مجدد در هر بار استفاده درخواست می‌شود.

توکن‌های GitHub در فضای ذخیره‌سازی سرور با AES-GCM رمزنگاری می‌شوند. اطلاعات مخزن و کدهایی که برای تحلیل انتخاب می‌کنید ممکن است برای انجام درخواست به سرویس مدل هوش مصنوعی ارسال شوند.

قطع اتصال و لغو مجوز GitHub

  1. در محیط چت وارد بخش «کدنویس» شوید و گزینه بررسی وضعیت یا مدیریت اتصال GitHub را باز کنید.
  2. گزینه «قطع اتصال GitHub» را انتخاب کنید. توکن ذخیره‌شده در آناناس حذف می‌شود.
  3. برای لغو مجوز از سمت GitHub نیز به تنظیمات برنامه‌های مجاز GitHub بروید و دسترسی AnanasAI را لغو کنید.

قطع اتصال، شاخه‌ها، commitها یا Pull Requestهایی را که قبلاً با درخواست شما در GitHub ایجاد شده‌اند حذف نمی‌کند. برای حذف آن موارد باید مستقیماً در GitHub اقدام کنید.

۵. استفاده از سرویس‌های پردازش هوش مصنوعی

برای تولید پاسخ، تحلیل کد و فایل، خلاصه‌سازی ایمیل و پردازش درخواست‌ها، متن یا محتوایی که برای انجام آن درخواست لازم است ممکن است به سرویس‌های مدل هوش مصنوعی از جمله Google Gemini ارسال شود. این انتقال فقط برای ارائه قابلیت درخواستی انجام می‌شود. اطلاعات حساب Google یا GitHub برای تبلیغات یا فروش به اشخاص ثالث ارائه نمی‌شود.

زیرساخت میزبانی و ذخیره‌سازی سرویس از ارائه‌دهندگان فنی مانند Cloudflare استفاده می‌کند. هر ارائه‌دهنده فقط در حد لازم برای میزبانی، امنیت، پردازش درخواست یا ذخیره‌سازی داده درگیر می‌شود و پردازش داده نزد آن‌ها تابع شرایط و سیاست‌های همان ارائه‌دهنده نیز هست.

۶. ذخیره‌سازی، امنیت و مدت نگهداری

  • تاریخچه گفتگوهای عمومی در حافظه محلی مرورگر ذخیره می‌شود و با پاک‌کردن داده‌های سایت در مرورگر از همان دستگاه حذف خواهد شد.
  • تاریخچه گفتگوهای منشی و کدنویس برای همگام‌سازی در فضای ذخیره‌سازی سرور نگهداری می‌شود تا زمانی که کاربر آن را حذف کند یا درخواست حذف داده ثبت و اجرا شود.
  • توکن‌های اتصال Google و GitHub تا زمان قطع اتصال یا حذف داده‌های حساب نگهداری می‌شوند.
  • پیش‌نویس‌های موقت تغییرات کدنویس دارای زمان انقضا هستند؛ پیش‌نویس ثبت‌شده در GitHub ممکن است تا زمان حذف از خود GitHub باقی بماند.
  • فایل‌های صوتی کتابخانه محلی با حذف از کتابخانه یا پاک‌کردن داده‌های مرورگر حذف می‌شوند. تصاویر کتابخانه آنلاین از داخل همان کتابخانه قابل حذف هستند.

برای محافظت از داده‌ها از ارتباط HTTPS، کنترل دسترسی مبتنی بر حساب/اشتراک و رمزنگاری توکن‌های OAuth در فضای ذخیره‌سازی استفاده می‌شود. با وجود این تدابیر، هیچ روش انتقال یا ذخیره‌سازی اینترنتی را نمی‌توان صددرصد مصون از خطر دانست.

۷. چگونه اطلاعات یا حساب خود را حذف کنم؟

برای حذف اطلاعات، لازم نیست درخواست پیچیده‌ای ثبت کنید. مسیرهای زیر در دسترس هستند:

  1. حذف یک گفتگو: در فهرست تاریخچه محیط چت، منوی همان گفتگو را باز و «پاک کردن گفتگو» را انتخاب کنید. این کار نسخه ذخیره‌شده گفتگوهای منشی و کدنویس را نیز از سرور حذف می‌کند.
  2. حذف همه گفتگوها: در پنل کناری محیط چت روی «حذف همه» بزنید و تأیید کنید. گفتگوهای محلی و همه تاریخچه‌های همگام‌شده منشی و کدنویس از فهرست و فضای ذخیره‌سازی سرور حذف می‌شوند.
  3. حذف تصاویر یا فایل‌های صوتی: هر تصویر را از کتابخانه تصاویر آنلاین حذف کنید و فایل صوتی را از کتابخانه صوتی همان دستگاه پاک کنید. پاک‌کردن داده‌های مرورگر نیز اطلاعات محلی را حذف می‌کند.
  4. حذف داده‌های اتصال Google یا GitHub: از گزینه «قطع اتصال» در بخش منشی یا کدنویس استفاده کنید و در صورت تمایل مجوز را از تنظیمات امنیتی Google یا GitHub نیز لغو کنید.
  5. درخواست حذف داده‌های حساب و سوابق سروری: از پشتیبانی رسمی آناناس پیام بدهید و صریحاً درخواست «حذف داده‌های حساب و اطلاعات مرتبط» را ثبت کنید. پس از احراز مالکیت حساب، داده‌های قابل شناسایی و قابل حذف در سامانه پاک‌سازی می‌شوند. درخواست‌ها حداکثر ظرف ۳۰ روز بررسی و اجرا یا نتیجه و محدودیت قانونی احتمالی به کاربر اعلام می‌شود.

حذف داده از آناناس، محتوایی را که قبلاً در حساب Google یا GitHub شما ایجاد شده است (مانند ایمیل ارسال‌شده، رویداد تقویم، commit یا Pull Request) حذف نمی‌کند. آن محتوا باید در سرویس اصلی مربوطه حذف شود. نسخه‌های پشتیبان یا سوابقی که نگهداری آن‌ها به دلایل امنیتی، حل اختلاف یا الزامات قانونی ضروری باشد ممکن است برای مدت محدود باقی بمانند و سپس طبق چرخه نگهداری حذف شوند.

برای حفاظت از حساب، هیچ‌گاه کد کامل اشتراک، رمز عبور Google/GitHub یا توکن دسترسی را در درخواست پشتیبانی ارسال نکنید. تیم پشتیبانی روش امن احراز مالکیت را اعلام می‌کند.

۸. حقوق و انتخاب‌های شما

شما می‌توانید از اتصال Google و GitHub صرف‌نظر کنید و همچنان از قابلیت‌هایی که به این اتصال‌ها نیاز ندارند استفاده کنید. همچنین می‌توانید تاریخچه و رسانه‌های قابل حذف را پاک کنید و برای دریافت اطلاعات مربوط به داده‌های خود، اصلاح یا حذف آن‌ها با پشتیبانی تماس بگیرید. در مواردی که قوانین حفاظت از داده محل اقامت شما اعمال می‌شود، حقوق قانونی مربوط به دسترسی، اصلاح، حذف، محدودسازی یا اعتراض به پردازش نیز قابل پیگیری است.

۹. حریم خصوصی کودکان

آناناس برای ارائه قابلیت‌های عمومی هوش مصنوعی طراحی شده است. کودکان و نوجوانان باید با راهنمایی والدین یا سرپرست قانونی از سرویس استفاده کنند. اگر سرپرست قانونی معتقد است اطلاعات کودک بدون رضایت مناسب ثبت شده است، می‌تواند از طریق پشتیبانی درخواست بررسی و حذف آن را مطرح کند.

۱۰. تغییرات این سیاست

ممکن است این سیاست در صورت اضافه‌شدن قابلیت‌ها، تغییر شیوه پردازش داده یا تغییر الزامات قانونی به‌روزرسانی شود. نسخه جدید از همین نشانی منتشر می‌شود و تاریخ آخرین به‌روزرسانی در ابتدای صفحه درج خواهد شد.
