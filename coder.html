هنوز متصل نشده
برای نمایش پروژه‌ها باید حساب GitHub خود را متصل کنید. در مرحله تأیید GitHub، مجوز دسترسی به مخازن درخواست می‌شود. این مجوز برای خواندن و ثبت تغییرات در شاخه جداگانه استفاده خواهد شد.

توکن GitHub در مرورگر ذخیره نمی‌شود؛ اتصال رمزگذاری‌شده در فضای امن سمت سرور نگهداری می‌شود. هر زمان بخواهید می‌توانید دسترسی آناناس را از تنظیمات GitHub لغو کنید.
