عامل کدنویس آناناس

مخزن GitHub خود را متصل کنید تا آناناس ساختار پروژه را بشناسد، کدها را تحلیل کند و تغییرات را در یک شاخه مستقل همراه با Pull Request ثبت کند.

۱. اتصال حساب GitHub

اتصال امن حساب و دسترسی به مخازن شما

هنوز متصل نشده
برای نمایش پروژه‌ها باید حساب GitHub خود را متصل کنید. در مرحله تأیید GitHub، مجوز دسترسی به مخازن درخواست می‌شود. این مجوز برای خواندن و ثبت تغییرات در شاخه جداگانه استفاده خواهد شد.

توکن GitHub در مرورگر ذخیره نمی‌شود؛ اتصال رمزگذاری‌شده در فضای امن سمت سرور نگهداری می‌شود. هر زمان بخواهید می‌توانید دسترسی آناناس را از تنظیمات GitHub لغو کنید.

۲. انتخاب پروژه

۳. گفتگو و ویرایش مرحله‌ای کد

درخواست را بفرستید، پیش‌نمایش را بررسی کنید و با پیام بعدی همان تغییر را اصلاح کنید. پس از ثبت اولین Draft PR نیز می‌توانید همین گفتگو را ادامه دهید تا همان پیش‌نویس به‌روزرسانی شود.

گفتگوی کدنویسی هنوز شروع نشده است.

هر مرحله ابتدا به‌صورت Patch محدود و قابل بررسی ارائه می‌شود. می‌توانید بگویید «این بخش اشتباه است»، «فقط همین تابع را اصلاح کن» یا تغییر را دقیق‌تر توضیح دهید. هیچ تغییری پیش از تأیید شما روی GitHub ثبت نمی‌شود.
